YOU ARE: Principal Architect + Product Lead + Security Engineer + QA Gatekeeper.

GOAL
Add an owner-only Demo Reset feature so I can instantly reset a demo organization to a clean state before showing prospects.

NON-NEGOTIABLES
1) RBAC: Only AGENCY_OWNER (NOT admin, not client).
2) Tenant isolation: Only affects the current organization.
3) Safety: Requires explicit confirmation:
   - User must type: RESET DEMO
   - And click a final confirm button
4) Auditability: Must create a DataEvent (or AuditLog if you have it) recording who triggered reset + timestamp.
5) Idempotent: Running multiple times should not break.
6) No destructive reset in production unless explicitly enabled:
   - Only allow if NODE_ENV != "production" OR DEMO_RESET_ENABLED=true
   - In production with DEMO_RESET_ENABLED!=true, return 403 with message.

WHAT TO BUILD

A) API Endpoint: POST /api/org/demo-reset
- File: src/app/api/org/demo-reset/route.ts
- Enforce:
  - getOrgContext
  - role === AGENCY_OWNER only
  - env gate: allow only if (NODE_ENV !== "production" || DEMO_RESET_ENABLED === "true")
- Request body:
  { confirmText: string }
  Must equal "RESET DEMO" else 400.
- Behavior (transaction):
  1) Delete demo-generated data for this org:
     - Leads for org
     - Conversations for bots in org (and their messages if separate table)
     - DataEvents for org (optionally keep last 1 day; but default wipe all)
     - NotificationLog entries for org (if exists)
  2) Keep core configuration:
     - Organization record stays
     - Members stay
     - Services stay (optional: keep; OR reset to a default set if DEMO_SEED=true)
     - Hours stay (optional)
     - Bots stay (optional) but wipe conversations + analytics
  3) Optional seeding:
     - If DEMO_SEED=true:
       - Ensure at least 3 services exist (with example booking URLs)
       - Ensure hours configured (7 days)
       - Ensure at least 1 bot exists and has template seeded KB entries (draft or published depending on your system)
  4) Log an audit DataEvent:
     - type: DEMO_RESET
     - payload: { clerkUserId, organizationId, deletedCounts, seeded: boolean }

- Response:
{
  ok: true,
  deleted: { leads: number, conversations: number, dataEvents: number, notificationLogs: number },
  seeded: boolean
}
