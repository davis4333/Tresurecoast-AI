TASK: Step 20 Security Fix — Remove Same-Origin Bypass, Require Admin Key Always

GOAL
- /api/admin/bots and /api/admin/bots/[botPublicKey] must never be callable without auth.
- Remove the “same-origin” bypass completely.
- Require header x-admin-key for ALL requests.
- Use env var ADMIN_API_KEY (not ADMIN_SEED_KEY).
- Keep existing handler logic the same otherwise.
- Update docs and rerun QA gates.

FILES TO CHANGE

1) MODIFY: src/lib/admin/requireAdmin.ts
Replace it with this exact implementation:

import { NextResponse } from "next/server";

export function requireAdmin(req: Request): void {
  const adminKey = process.env.ADMIN_API_KEY;
  if (!adminKey) {
    // server misconfigured
    throw NextResponse.json({ ok: false, error: "server_misconfigured" }, { status: 500 });
  }

  const provided = req.headers.get("x-admin-key");
  if (!provided || provided !== adminKey) {
    throw NextResponse.json({ ok: false, error: "unauthorized" }, { status: 401 });
  }
}

Notes:
- No Origin/Referer/Host checks.
- No bypasses.
