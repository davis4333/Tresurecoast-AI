## Functional Testing (Manual)

### Test Case 1: Happy Path (Full Flow)

**Setup**: Ensure at least 1 active service with bookingUrl

1. **Start booking**
   - User: "I want to book"
   - [ ] State → SERVICE_SELECTION
   - [ ] Shows service picker with available services

2. **Select service**
   - User: clicks "Haircut" (or enters service name)
   - [ ] State → LEAD_NAME
   - [ ] Shows name prompt

3. **Enter name**
   - User: "John Smith"
   - [ ] State → LEAD_PHONE
   - [ ] Shows phone prompt
   - [ ] Name stored in context

4. **Enter phone**
   - User: "(123) 456-7890"
   - [ ] State → LEAD_EMAIL
   - [ ] Shows email prompt
   - [ ] Phone normalized to "1234567890"

5. **Enter email**
   - User: "john@example.com"
   - [ ] State → COMPLETE
   - [ ] Shows booking link
   - [ ] Lead created in database
   - [ ] Email normalized to lowercase

6. **Verify lead**
   ```sql
   SELECT * FROM leads WHERE email = 'john@example.com' ORDER BY created_at DESC LIMIT 1;
   ```
   - [ ] Lead exists
   - [ ] `name = "John Smith"`
   - [ ] `phone = "1234567890"`
   - [ ] `email = "john@example.com"`
   - [ ] `metadata.selectedServiceId` matches selected service
   - [ ] `metadata.bookingUrl` is correct URL

7. **Verify events**
   ```sql
   SELECT event_type FROM data_events WHERE conversation_id = ? ORDER BY created_at;
   ```
   - [ ] BOOKING_FLOW_STARTED
   - [ ] SERVICE_SELECTED
   - [ ] LEAD_CAPTURED
   - [ ] BOOKING_LINK_SHOWN

**Test Case 1 Status: PASS / FAIL**
