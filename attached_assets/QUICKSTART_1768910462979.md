## Integration (5 Steps)

### Step 1: Add to Conversation Schema

If not already present:

```prisma
model Conversation {
  id      String @id @default(cuid())
  context Json?  // Will store bookingFlow state
  // ... rest of fields
}
```

### Step 2: Create Helper Function

In your chat handler file (e.g., `app/api/public/chat/route.ts`):

```typescript
import { transition, initBookingContext } from "@/lib/booking/bookingFlowMachine";
import type { SelectedService } from "@/lib/booking/bookingFlowTypes";

async function getServices(orgId: string): Promise<SelectedService[]> {
  const services = await prisma.organizationService.findMany({
    where: { organizationId: orgId, isActive: true },
    select: { id: true, name: true, bookingUrl: true, paymentUrl: true },
  });
  return services;
}
```

### Step 3: Add to Chat Handler

```typescript
// Inside your chat message handler
const context = conversation.context?.bookingFlow || initBookingContext();
const services = await getServices(organizationId);

const result = transition(context, { text: message }, services);

if (result.shouldPersist) {
  await prisma.conversation.update({
    where: { id: conversation.id },
    data: { context: { bookingFlow: result.context } },
  });
}

// Handle COMPLETE state
if (result.state === "COMPLETE") {
  await prisma.lead.create({
    data: {
      organizationId,
      botId,
      conversationId: conversation.id,
      name: result.context.leadDraft.name!,
      phone: result.context.leadDraft.phone!,
      email: result.context.leadDraft.email!,
      metadata: {
        selectedServiceId: result.context.selectedService!.id,
        selectedServiceName: result.context.selectedService!.name,
      },
      source: "BOOKING_FLOW",
    },
  });
}

return result.directive;
```

## Common Issues & Fixes

### Issue: "Can't find module '@/lib/booking/...'"

**Fix**: Check your `tsconfig.json` has path alias:
```json
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

### Issue: Tests fail with "Cannot find module"

**Fix**: Check `vitest.config.ts` has correct alias resolution:
```typescript
resolve: {
  alias: {
    "@": path.resolve(__dirname, "./src"),
  },
}
```

### Issue: State not persisting

**Fix**: Ensure you're calling `prisma.conversation.update()` when `result.shouldPersist = true`

### Issue: Lead not created

**Fix**: Check that `result.state === "COMPLETE"` before creating lead

### Issue: Booking URL is undefined

**Fix**: 
1. Check `OrganizationService` has `bookingUrl` or `paymentUrl`
2. Verify service is active (`isActive: true`)
