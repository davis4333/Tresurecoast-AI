PHASE 2 — DESIGN SYSTEM (TOKENS + COMPONENT RULES)
===========================================================
STEP 3: Establish a “Premium Agency” Design System
Create or refine a consistent design system with tokens:
A) Typography
- Choose ONE font stack (or two max: display + body) that feels premium.
- Define:
  - font-family tokens
  - font sizes (12/14/16/18/20/24/32/40)
  - line heights
  - font weights
  - letter spacing
- Define consistent heading styles:
  - H1/H2/H3, section titles, card titles, labels, helper text

B) Color System (Dark-luxury + neon-glass accents is OK, but must be tasteful)
- Define:
  - background layers (app bg, surface 1, surface 2)
  - borders (subtle, consistent)
  - text colors (primary, secondary, muted)
  - brand accent(s)
  - semantic colors (success/warn/error/info)
  - chart palette (subtle, not clowny)
- Ensure good contrast ratios.

C) Spacing + Layout
- Define spacing scale: 4/8/12/16/20/24/32/40/48/64
- Define max widths for content sections
- Define page header layout rules (title, description, actions)
- Define consistent padding for cards/tables/modals

D) Radii + Shadows
- Define radii tokens: sm/md/lg
- Define shadow tokens: subtle elevation only

E) Motion
- Subtle transitions only:
  - hover transitions (150–200ms)
  - modal open/close
  - toasts
- No flashy gimmicks.

Deliverable:
- src/lib/ui/tokens.ts (or Tailwind config tokens)
- docs/DESIGN_SYSTEM_TOKENS.md

STEP 4: Component Specs (Single Source of Truth)
Create standardized component styles for:
- Buttons (primary/secondary/ghost/destructive)
- Inputs (default/focus/error/disabled)
- Selects
- Modals + Drawers (headers, footers, close button placement)
- Cards (title spacing, divider rules)
- Tables (striping, hover, header emphasis)
- Badges/Chips
- Toasts (consistent placement and styling)
- Skeletons
- Empty states (icon + title + helpful guidance + CTA)
- Charts (axis label sizes, legend style)

Deliverable:
- docs/UI_COMPONENT_SPEC.md
- Ensure components are used consistently across all pages.
