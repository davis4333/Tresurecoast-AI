B1) Create shared helper: src/lib/public/hostPolicy.ts

It must export:

type HostPolicyResult =
  | { ok: true; mode: "platform" | "custom_domain"; host: string; orgId?: number }
  | { ok: false; status: 400|403|500; error: string; message: string };

function getRequestHost(req: Request): string | null
- Prefer x-forwarded-host if present; else host.
- Normalize: lowercase; strip port; trim.
- Return null if missing.

function getOriginHost(req: Request): string | null
- Read Origin header; parse URL; return hostname lowercase.
- If invalid, return null.

async function resolveHostPolicy(req: Request): Promise<HostPolicyResult>
- host = getRequestHost(req); if null -> {ok:false,status:400,error:"missing_host"}
- Query DB for org by customDomain == host (case-insensitive match by normalized lowercase stored value; assume stored normalized).
  Use prisma.organization.findFirst({ where: { customDomain: host }, select: { id:true, customDomainStatus:true } })
- If no org found: return { ok:true, mode:"platform", host }
- If org found AND customDomainStatus !== "verified":
  return { ok:false, status:403, error:"custom_domain_not_verified", message:"Custom domain is not verified yet" }
- If org found AND customDomainStatus === "verified":
  return { ok:true, mode:"custom_domain", host, orgId: org.id }

function isHostAllowed(allowlistDomains: string[] | null | undefined, origin: string | null, host: string | null): boolean
- Move the CURRENT duplicated behavior into this helper (do not change semantics).
- It must behave exactly like existing routes today to avoid regressions.

async function enforceTenantBinding(opts: {
  req: Request;
  botOrgId: number;
}): Promise<HostPolicyResult>
- policy = await resolveHostPolicy(req)
- If policy.ok === false -> return policy
- If policy.mode === "platform" -> return policy (no tenant-binding enforcement)
- If policy.mode === "custom_domain":
    if policy.orgId !== botOrgId:
      return { ok:false, status:403, error:"cross_tenant_host", message:"Host is bound to a different organization" }
    else return policy

NOTE: We only enforce tenant binding when the host is a claimed domain. Platform hosts keep existing behavior.
