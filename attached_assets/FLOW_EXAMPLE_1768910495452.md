This document shows a complete booking flow conversation with all state transitions, data structures, and database records.

## Message Flow

### Message 1: Initial Greeting

**User Input:**
```
Hey, what services do you offer?
```

**State Machine Input:**
```javascript
{
  currentContext: { state: "IDLE", leadDraft: {}, errors: [] },
  input: { text: "Hey, what services do you offer?" },
  availableServices: [/* 3 services */]
}
```

**Transition:**
- Detects booking intent: `isBookingIntent("what services do you offer")` → `true`
- Transition: `IDLE` → `SERVICE_SELECTION`

**Result:**
```javascript
{
  state: "SERVICE_SELECTION",
  context: {
    state: "SERVICE_SELECTION",
    leadDraft: {},
    startedAt: "2026-01-20T10:30:00Z",
    errors: [],
  },
  directive: {
    type: "SHOW_SERVICE_PICKER",
    message: "Great! What service are you interested in?",
    services: [
      { id: "svc_haircut_123", name: "Men's Haircut", ... },
      { id: "svc_beard_456", name: "Beard Trim & Line Up", ... },
      { id: "svc_shave_789", name: "Hot Towel Shave", ... },
    ],
  },
  shouldPersist: true,
}
```

**UI Renders:**
```
Bot: "Great! What service are you interested in?"

[Button: Men's Haircut]
[Button: Beard Trim & Line Up]
[Button: Hot Towel Shave]
```

**Database After Message 1:**

### Message 2: Service Selection

**User Input:**
```
[Clicks "Men's Haircut" button]
selectedServiceId: "svc_haircut_123"
```

**State Machine Input:**
```javascript
{
  currentContext: {
    state: "SERVICE_SELECTION",
    leadDraft: {},
    startedAt: "2026-01-20T10:30:00Z",
    errors: [],
  },
  input: {
    text: "Men's Haircut", // From button label
    selectedServiceId: "svc_haircut_123",
  },
  availableServices: [/* 3 services */]
}
```

**Transition:**
- Service matched by ID: `svc_haircut_123`
- Transition: `SERVICE_SELECTION` → `LEAD_NAME`

**Result:**
```javascript
{
  state: "LEAD_NAME",
  context: {
    state: "LEAD_NAME",
    selectedService: {
      id: "svc_haircut_123",
      name: "Men's Haircut",
      bookingUrl: "https://square.site/book/sunset-barber/haircut",
      paymentUrl: null,
    },
    leadDraft: {},
    startedAt: "2026-01-20T10:30:00Z",
    errors: [],
  },
  directive: {
    type: "ASK_FOR_NAME",
    message: "Perfect! I've got you down for Men's Haircut. What's your name?",
  },
  shouldPersist: true,
}
```

**UI Renders:**
```
Bot: "Perfect! I've got you down for Men's Haircut. What's your name?"

[Text input field]
```

### Message 5: Email Entry & Completion

**User Input:**
```
Marcus.J@Gmail.com
```

**State Machine Input:**
```javascript
{
  currentContext: {
    state: "LEAD_EMAIL",
    selectedService: {
      id: "svc_haircut_123",
      name: "Men's Haircut",
      bookingUrl: "https://square.site/book/sunset-barber/haircut",
      paymentUrl: null,
    },
    leadDraft: {
      name: "Marcus Johnson",
      phone: "7725550142",
    },
    ...
  },
  input: { text: "Marcus.J@Gmail.com" },
  availableServices: [/* 3 services */]
}
```

**Validation:**
```javascript
validateEmail("Marcus.J@Gmail.com")
// Returns: { isValid: true, value: "marcus.j@gmail.com" } // Lowercased
```

**Transition:**
- Email valid and normalized
- Transition: `LEAD_EMAIL` → `COMPLETE`
- bookingUrl found: `"https://square.site/book/sunset-barber/haircut"`

**Result:**
```javascript
{
  state: "COMPLETE",
  context: {
    state: "COMPLETE",
    selectedService: {
      id: "svc_haircut_123",
      name: "Men's Haircut",
      bookingUrl: "https://square.site/book/sunset-barber/haircut",
      paymentUrl: null,
    },
    leadDraft: {
      name: "Marcus Johnson",
      phone: "7725550142",
      email: "marcus.j@gmail.com", // Normalized to lowercase
    },
    startedAt: "2026-01-20T10:30:00Z",
    completedAt: "2026-01-20T10:32:15Z",
    errors: [],
  },
  directive: {
    type: "SHOW_BOOKING_LINK",
    message: "Perfect! Here's your booking link for Men's Haircut:",
    bookingUrl: "https://square.site/book/sunset-barber/haircut",
  },
  shouldPersist: true,
}
```

**UI Renders:**
```
Bot: "Perfect! Here's your booking link for Men's Haircut:"
```

### Scenario: Service with NO booking URL

**Selected Service:**
```javascript
{
  id: "svc_shave_789",

  paymentUrl: null, // ❌ No URL
```

**Lead still created** with all data, but no link shown.

### Scenario: User Cancels Mid-Flow

**At LEAD_PHONE state:**

**User Input:** `"cancel"`

**Result:**
```javascript
{
  state: "IDLE",
  context: {
    state: "IDLE",
    leadDraft: {}, // Cleared
    errors: [],
  },
  directive: {
    type: "CONTINUE_CHAT",
    message: "No problem! Booking cancelled. Let me know if you need anything else.",
  },
  shouldPersist: true,
}
```

**No lead created** ✅

### Scenario: Invalid Input (stays in same state)

**At LEAD_EMAIL state:**

**User Input:** `"notanemail"`

**Validation:**
```javascript
validateEmail("notanemail")
// Returns: { isValid: false, error: "Please enter a valid email address..." }
```

**Result:**
```javascript
{
  state: "LEAD_EMAIL", // ❗ Stays in same state
  context: {
    state: "LEAD_EMAIL",
    selectedService: { /* ... */ },
    leadDraft: {
      name: "Marcus Johnson",
      phone: "7725550142",
      // email NOT added
    },
    errors: ["Please enter a valid email address (e.g., name@example.com)."],
  },
  directive: {
    type: "ASK_FOR_EMAIL",
    message: "Please enter a valid email address (e.g., name@example.com).",
    error: "Please enter a valid email address (e.g., name@example.com).",
  },
  shouldPersist: false, // ❗ Don't persist failed validation
}
```

**Flow continues** - user can try again.

## Key Takeaways

✅ **Deterministic**: Every state transition is predictable  
✅ **No hallucinations**: URLs only from database  
✅ **Interrupt-safe**: Cancel/restart/back work from any state  
✅ **Validation**: Proper error messages for invalid inputs  
✅ **Persistence**: Context saved after each successful transition  
✅ **Events**: Full audit trail for analytics  
✅ **Lead capture**: Atomic creation on COMPLETE only  
✅ **Graceful degradation**: Handles missing URLs elegantly  

This is production-ready booking flow! 🚀
